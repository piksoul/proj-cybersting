## Summary

A darker, crew-focused thriller where Elias learns to trust again after failing to save Sarah. The crew coordinates a precision sequence that succeeds where his solo effort failed. Trust is the skill being tested.

**Tone**: Darker (6-7 on darkness scale) — harder-won victory, guilt redeemed not erased
**Scope**: Intimate — smaller action, crew essential
**Crew Role**: Essential action at climax (not just teaching)

## Precision Sequence Options

Test writing needed to determine which works best:

| Option | Description | Trust Test Level |
|--------|-------------|------------------|
| **Offline signal chain** | Crew relays info manually (no comms); trust the chain | Very high |
| **Many hands** | Multiple simultaneous actions required | Very high |
| **Physical obstacles** | Timed challenge; crew creates windows | High |
| **Too many buttons** | Literally can't be done by one person | High (elegant) |
| **Handoff** | Elias starts, must let crew finish | High |
| **Fight + execute** | Crew holds threats; Elias acts | Medium |
| **Getaway** | Coordinated escape after action | Lower |

**Recommendation**: Test "Many hands" or "Offline signal chain" — both force Elias to let go completely.

## Emergence: External vs Internal (Earthsea)

Must test write both to decide:

### External Version
- Emergence is equalizing force in the network
- Crew coordinates with/around it
- Resolution: Emergence deletes keys, disappears
- Elias helped but Emergence is separate entity
- **Transcendence**: Medium (5-6)

### Internal/Earthsea Version
- Emergence is Elias's dissociated pattern-sight
- His burnout after Sarah caused a psychological split
- Resolution: He integrates the shadow-self
- System reflects his internal state
- **Transcendence**: High (7-8)
- **Risk**: "All in his head" can feel cheap if not set up properly

**Foreshadowing for Earthsea**: Pattern-sight must feel increasingly strange; dissociation must be present behavior, not just backstory.
