# Narrative Structure Decisions

## Purpose

Deciding how the story is organised in time—linear, nonlinear, parallel, framed. Structure choices that shape reader experience.

Reference: `docs/craft/narrative-structure.md`

---

## Structure Type Options

### Option A: Linear/Chronological

| Aspect | Detail |
|--------|--------|
| **Description** | Story told in order events occur |
| **Backstory handling** | Revealed through dialogue, documents, brief flashbacks |
| **Advantage** | Easiest to follow; momentum maintained |
| **Limitation** | Backstory must be integrated carefully |
| **Genre fit** | Most thrillers; Clancy, Crichton |

### Option B: Cyclic

| Aspect | Detail |
|--------|--------|
| **Description** | Opens near the end, jumps back, progresses to opening, continues past |
| **Effect** | Creates anticipation ("how do we get here?") |
| **Advantage** | Hooks reader with dramatic moment |
| **Limitation** | Middle can sag if opening scene is too climactic |
| **Genre fit** | Some literary thrillers |

**Example opening**: Start with Elias in ARCHITECT confrontation, then "72 hours earlier..."

### Option C: Nonlinear/Fractured

| Aspect | Detail |
|--------|--------|
| **Description** | Story told out of chronological order |
| **Techniques** | Extended flashbacks, multiple timelines |
| **Advantage** | "Why" revealed before "what"; juxtaposition creates meaning |
| **Limitation** | Can confuse; requires skilled execution |
| **Genre fit** | Literary; Gibson's later work |

### Option D: Dual Timeline

| Aspect | Detail |
|--------|--------|
| **Description** | Two timelines running in parallel (e.g., present + past) |
| **Backstory handling** | Past timeline IS the backstory; revealed in full scenes |
| **Advantage** | Deep exploration of kompromat/origin |
| **Limitation** | Doubles narrative burden; past must be compelling |
| **Genre fit** | Literary thriller; *Cryptonomicon* |

**Example**: Alternating chapters between present operation and 12-years-ago origin.

## Backstory Integration Methods

Given our rich backstory (kompromat, Bitcoin origin, Satoshi witness), how do we reveal it?

### Method 1: Breadcrumb Trail (Linear + Hints)

| Aspect | Detail |
|--------|--------|
| **Technique** | Linear present; past revealed through dialogue, memory flashes, documents |
| **Pacing** | Information drips throughout |
| **Advantage** | Maintains forward momentum; mystery builds |
| **Risk** | Can feel like withholding if overdone |

### Method 2: Strategic Flashbacks (Linear + Scenes)

| Aspect | Detail |
|--------|--------|
| **Technique** | Linear present with 2-4 full flashback scenes |
| **Pacing** | Most action in present; flashbacks at key revelation points |
| **Advantage** | Scenes more vivid than hints; emotional weight |
| **Risk** | Flashbacks must earn their length |

### Method 3: Dual Timeline (Parallel)

| Aspect | Detail |
|--------|--------|
| **Technique** | Present and past as equal narrative threads |
| **Pacing** | Alternating chapters or sections |
| **Advantage** | Maximum backstory depth; past is active story |
| **Risk** | Past must be as compelling as present; doubles scope |

### Method 4: Document Reveals (Epistolary Elements)

| Aspect | Detail |
|--------|--------|
| **Technique** | Backstory revealed through in-world documents |
| **Examples** | Old code commits, intercepted messages, dossiers, recordings |
| **Advantage** | Texture; unreliable "found" feel |
| **Risk** | Can break immersion if overused |

## Working Hypothesis

### Recommended: Linear with Strategic Flashbacks + Documents

**Primary structure**: Linear chronological (present action)

**Backstory integration**:
- Breadcrumbs throughout (hints, references, emotional reactions)
- 2-3 strategic flashback scenes at key moments
- Document reveals for specific information (code, messages)
- One earned extended flashback for emotional climax of backstory

### Why This Approach?

1. **Thriller momentum**: Linear keeps pace; reader isn't confused
2. **Mystery preserved**: We discover with Elias
3. **Emotional peaks**: Flashbacks placed for maximum impact
4. **Genre appropriate**: Matches le Carré, Gibson (mostly linear, strategic non-linearity)
5. **Scope controlled**: Not committing to full dual timeline

### When Flashbacks Occur

| Timing | Flashback Content | Function |
|--------|-------------------|----------|
| **~25%** (Act 1 end) | First hint of kompromat; brief flash | Establish wound exists |
| **~50%** (Midpoint) | Antagonist confrontation triggers memory | Revelation of what happened |
| **~75%** (All Is Lost) | Full flashback scene | Emotional weight; understands why it matters |
| **Climax area** | Brief flash or none | Present action dominates |

## Framing Considerations

### Do We Need a Frame?

| Frame Type | Application | Assessment |
|------------|-------------|------------|
| **Bookend** | Opens at end, returns to start | Not necessary; could work for cyclic |
| **Epistolary** | Told through documents | Too artificial for thriller |
| **Nested** | Story within story | Doesn't fit our structure |
| **None** | Straight narrative | **Recommended** |

### Recommendation: No Frame

- Direct narrative entry
- Opens with Elias in present (ordinary world or catalyst)
- Ends in present (new equilibrium)
- Frame would add complexity without benefit

## Opening Strategy

### Six Types of Openings

| Type | Description | Fit for Our Story |
|------|-------------|-------------------|
| **Personal** | Intimate, character-focused | Good - establish Elias |
| **Odd/Discord** | Something strange | Could work - mysterious message |
| **Dramatic** | Action, tension | Could work - in media res |
| **Reflective** | Philosophical | Less suitable for thriller |
| **Poetic** | Lyrical | Not our tone |
| **Proverbial** | Universal truth | Could work if earned |

### Recommended Opening: Personal + Discord

Combine:
- **Personal**: Elias in his ordinary world (climbing wall? apartment?)
- **Discord**: Something disrupts (the message, a sign of the past)

**Not** starting in media res at the height of action—earn the tension.

### Opening Scene Options

| Option | Description | Pros | Cons |
|--------|-------------|------|------|
| **A** | Elias climbing at dawn; message interrupts | Establishes character, skill, routine | Slow build |
| **B** | Elias receives message; must decide whether to respond | Immediate hook; establishes stakes | Less character establishment |
| **C** | Elias at Christmas with found family; message arrives | Shows relationships, stakes | Delays main plot |
| **D** | Flash forward to crisis; "72 hours earlier" | Immediate tension | Cyclic structure; can feel gimmicky |

### Questions to Resolve

- [ ] Which opening approach?
- [ ] How quickly to the inciting incident?
- [ ] Does opening establish found family or Elias alone?

## Ending Strategy

### Four Types of Endings

| Type | Description | Fit for Our Story |
|------|-------------|-------------------|
| **Optimistic** | Clear positive resolution | Possible - Christmas promise fulfilled |
| **Accepting** | Bittersweet, peace with loss | Possible - disillusionment arc |
| **Tainted Positive** | Victory with cost | Likely - spy thriller convention |
| **Ambiguous** | Open-ended | Less suitable - need closure on Christmas promise |

### Recommended Ending: Tainted Positive or Accepting

| Element | Resolution |
|---------|-----------|
| **Main plot** | ARCHITECT defeated/absorbed; emergence question open |
| **Father** | Reconciliation achieved; Christmas promise kept |
| **Found family** | Survives; bonds strengthened |
| **Dominik** | Consequences of betrayal (death or exile) |
| **Elias internally** | Transformed; lost certainty, gained connection |
| **Emergence** | Ambiguous - threat or promise? Not fully resolved |

This gives closure on emotional stakes while leaving conceptual questions open.

## Pacing Structure

### Three-Act Beat Timing

| Act | Percentage | Content | Pacing |
|-----|------------|---------|--------|
| **Act 1** | 0-25% | Setup, catalyst, first threshold | Building |
| **Act 2a** | 25-50% | Rising action, fun & games, midpoint | Accelerating |
| **Act 2b** | 50-75% | Complications, all is lost, dark night | Intense |
| **Act 3** | 75-100% | Climax, resolution | Peak then denouement |

### Scene Length Guidelines

| Scene Type | Length | Pacing |
|------------|--------|--------|
| Action sequences | Short chapters (2-3k) | Fast cuts |
| Emotional scenes | Medium (3-5k) | Room to breathe |
| Backstory flashbacks | Medium (3-4k) | Must earn length |
| Climax | Variable | Building to peak |
| Resolution | Short (2-3k) | Quick wrap |

## Timeline Considerations

### Story Present

| Aspect | Decision |
|--------|----------|
| **When set** | Near-future or present day |
| **Duration** | Days to weeks (not months) |
| **Christmas promise** | Anchors timeline—story ends at Christmas? |

### Story Past (Flashback Content)

| Aspect | Decision |
|--------|----------|
| **How long ago** | ~12 years (Bitcoin 2009-2013 era) |
| **Key events** | Kompromat event, Satoshi witness, original sin |
| **Duration covered** | Specific incidents, not extended period |

### Questions to Resolve

- [ ] Does story begin days or weeks before Christmas?
- [ ] Does climax fall ON Christmas or does resolution?
- [ ] How much time does main plot span?

## Multiple Timeline Management

If we include flashbacks, managing clarity:

### Signalling Techniques

| Technique | Application |
|-----------|-------------|
| **Section breaks** | White space before/after flashback |
| **Temporal markers** | "Twelve years ago" / "Now" |
| **Tense shift** | Present stays past tense; flashback could shift (or stay same) |
| **Chapter titles** | If using, can indicate timeframe |
| **Typography** | Italics for flashback (use sparingly) |

### Recommended: Section Breaks + Temporal Markers

Simple, clear signalling:
- Three asterisks or white space
- Opening line establishes when: "The night Chen died, the snow came early."
- Return to present with similar marker
