## Recommended Combo Character Set

For **#10 (Kill Switch + Sarah) + #4b (Crypto Scam)**:

| Character | Source | Role in Story |
|-----------|--------|---------------|
| **Sarah Chen** | #10 | Dead—emotional anchor, flashback presence |
| **Sarah's sister/mother** | #10 | Living moral weight, possible protection need |
| **Marcus Chen** | #4b | Scam founder—imprisoned? Dead? Wild card? |
| **Kill switch architect** | #10 | Built flawed version—incompetent or saboteur? |
| **Operation commander** | #10 | Knows truth about Sarah—potential reveal source |
| **The recorder** | #4b | Holds Austin video—faction leverage |
| **Father** | Core | Living family, Christmas anchor |
| **Berlin station contacts** | Setting | Handlers, parkour community |

This combination provides:
- One major dead character (Sarah) for emotional weight
- One potential returning antagonist (Marcus Chen or kill switch architect)
- One clear kompromat holder (the recorder)
- Family stakes (Sarah's relatives, Elias's father)
- Institutional antagonists (operation commander, recorder's faction)
