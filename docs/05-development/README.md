## What We're Testing

| Element | Question |
|---------|----------|
| **Plot** | Does the sequence of events work? |
| **Character** | Do they sound right? React believably? |
| **Emotion** | Does the scene land? |
| **Theme** | Does Control vs Adaptation come through? |
| **Pacing** | Right length? Right beats? |

---

## Process

1. **Write the scene** — Don't overthink, get it down
2. **Read aloud** — Does it flow? Does dialogue sound natural?
3. **Note observations** — What worked? What didn't? What surprised you?
4. **Decide** — Keep, revise, or cut this approach?
