# Development Homework Tasks

Quick reference for light creative work during deep research phase.

## Task Types

- **Scene sketches** - short moment captures, no full narrative needed
- **Vignettes** - 1-page standalone pieces exploring tone/atmosphere
- **Dialogue fragments** - character voice experiments, conversation snippets
- **Atmosphere descriptions** - location/mood evocations
- **Speculative inserts** - "what if" moments, concept tests
- **Location evocations** - place-based writing (Berlin clubs, breaking scenes, etc.)
- **Character voice experiments** - internal monologue, perspective shifts
- **Motif drafts** - recurring symbols, visual/thematic patterns
- **Spectacle pages** - media commentary, satire inserts
- **Conceptual diagrams** - visual thinking, relationship maps
- **Cryptographic puzzle ideas** - narrative devices, mystery elements

## Process

1. **During research**: Note 1-3 ideas per session
2. **After session**: Add single-sentence connection to story architecture
3. **Weekly**: Write one 10-minute sketch inspired by recent research

## Purpose

Keep creative muscles warm while filling the reservoir. These sketches become raw material for formalization later.
