Creative Hybrid Schedule

⭐ DAILY STRUCTURE (same for all 90 days)
40–60 min — Research Input
(audiobook or reading depending on theme)
15–30 min — Immediate Note Capture
→ 3 bullet notes max
→ 1 story application insight
20–40 min — Creative Output “Sketch”
→ scene fragment
→ dialogue snippet
→ location description
→ character moment
→ Spectacle Insert draft
→ diagram / map
→ audio ambience idea
→ interactive sequence idea
End of day — 1 sentence summary
“How today’s materials inform my story.”
That’s it.
90 days × 1 hour/day = monster progress.
